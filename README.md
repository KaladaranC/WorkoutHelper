# Spotter

An 8-week home workout plan for glutes, thighs, bust and waist. Your phone camera counts reps and gives spoken form feedback. Everything runs in the browser: no server, no account, and video never leaves the device.

```bash
npm install
npm run dev      # http://localhost:3000
npm test
npm run build    # static site in out/
```

Deploy by importing the repo into Vercel. No configuration is needed.

See [CLAUDE.md](CLAUDE.md) for architecture and conventions, and the in-app **Why this plan works** page for the training rationale and sources.
